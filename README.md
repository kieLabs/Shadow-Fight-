# Shadow Fight: Shadows of Eternity

An HTML5 Canvas 2D Silhouette Martial Arts Action RPG inspired by Nekki's *Shadow Fight 2*.

## Features
- **Responsive Landscape Design**: Auto-adapts to Mobile, Tablet, and Desktop screens with a virtual 8-way D-Pad and 4-button combat cluster.
- **Multiple Game Modes**: 6 Story Acts + Titan Finale, Underworld Clan Raids (Volcano, Megalith, Fungus), Endless Survival, and Shadow Duels.
- **Armory & Magic**: Unlock and equip Katanas, Cleavers, Bo Staffs, Kusarigama, Composite Swords, and Shadow Magic spells.
- **Avatars & Warriors**: Includes classic Shadow alongside new heroes like Neon Shinobi, Oni Warlord, and Eclipse Monk.

## How to Run / Deploy on GitHub Pages
1. Upload `index.html` and `README.md` to your GitHub repository.
2. Go to **Settings > Pages** and set the source branch to `main`.
3. Open the live GitHub Pages URL on Mobile (Landscape) or PC to play!
